# ChromaFix

**Developed by: Kavana**

ChromaFix is an image-processing project designed to improve the visibility of colors for people with Color Vision Deficiency (CVD). It modifies color combinations that may appear similar to people with color blindness and enhances their visual distinction.

The project aims to make images, charts, maps, diagrams, and other visual content easier to understand by applying color-correction techniques.

### Features
- Supports color-vision-deficiency correction
- Improves distinction between similar colors
- Provides before-and-after image comparisons
- Simple and user-friendly interface
- Helps make visual information more accessible

### Technologies Used
- Python
- OpenCV
- Flask
- HTML/CSS
- Image Processing

### Purpose
The goal of ChromaFix is to promote **accessible and inclusive visual content** by making important color-based information easier to distinguish for people with Color Vision Deficiency.
